These calculations are fixed in Phase 6B.1 and asserted explicitly in the tests.

## Test method and scope limits

- **New tests:** 13 test functions cover AC-02 through AC-13, including a separate negative hold test for AC-08. AC-01 has no fabricated passing test. The tests use only fictional SKUs, stock, lot IDs, approvers and dates.
- **Conservation:** For ECN cases with a published ledger, every component/date is checked against `opening usable + confirmed receipts − authorized holds − simulated use = closing usable`; physical stock is checked separately against opening physical plus confirmed receipts minus use. Legacy-scheduler cases reconcile each product turn against input opening stock, confirmed receipts and component use. All balances and builds must be nonnegative. Product demand is checked against completed plus unfinished units, and daily builds against capacity. AC-09 intentionally has no post-build ledger because the engine rejects the ambiguous plan.
- **Failure analysis:** The first focused run had 12 passes and one AC-13 test failure. The hand result was unchanged. The test expected the revision summary to omit zero B builds, but the engine reports `{"A": 150, "B": 0}`. The assertion was corrected to include the explicit zero; the next focused run passed 13/13. This was a test representation assumption, not a manufacturing calculation discrepancy.
- **Existing behavior:** The 189-test baseline passed before the new file was added. The final complete-suite result is recorded below. Existing tests were neither deleted nor weakened. Engine and dashboard files were not edited.
- **No transaction inference:** `actual_buildable_units` is an internal planning-result key inherited from earlier phases. The UI labels it simulated. Assertions on returned dictionaries and Streamlit AppTest cannot establish how a future external MES/ERP would behave.

## Outstanding practitioner decisions

AC-01 needs make/buy, subassembly stock netting, yield, routing, lead-time and revision rules before a multi-level oracle exists. AC-02 needs released-lot and shift/serial cutoff policy; AC-03–04 need supplier arrival versus inspection-release and recovery-window rules; AC-05 and AC-09 need approved product and lot dispatch priorities; AC-06 needs WIP issue/rework authority; AC-07 needs shift/labor calendars; AC-08 needs stock-status overlap and release authority; AC-10 needs MOQ/pack precedence; AC-11 needs disposition and accounting controls; AC-12 needs authoritative actual transaction records; AC-13 needs a dated revision-aware backlog replan policy. None is approved by these tests. The decision owners and required sign-off evidence are listed in Phase 6B.1's decision register and open-question table.

## Acceptance conclusion

The ready cases establish **internal conformance to the fictional current simulator rules** only. AC-01 and all named new-rule extensions remain blocked. Manufacturing, engineering, quality, production control and buying practitioners must approve the relevant policies and independently review their evidence before an operational EMS validation claim or new feature implementation.

**Final complete-suite run:** 202 passed (189 baseline tests plus 13 new tests); no failures.
